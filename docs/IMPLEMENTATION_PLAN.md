> Sumber: [`docs/ANALYSIS.md`](./ANALYSIS.md) (audit), [`integrations/n8n/README.md`](../integrations/n8n/README.md) (kontrak endpoint n8n), [`AGENTS.md`](../AGENTS.md) (aturan arsitektur).
